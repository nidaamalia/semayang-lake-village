# Desa Semayang

Landing page untuk Desa Wisata Semayang, Kutai Kartanegara, Kalimantan Timur.
Dibangun menggunakan React, Vite, Tailwind CSS, dan komponen dari shadcn-ui.

## Credit

Created by **webmedia.id**.

## Getting Started

1. `npm install`
2. `npm run dev` untuk menjalankan development server.
